# PR 본문 템플릿 (한국어)

한국 프로젝트에서 사용한다. `<...>`는 채워 넣을 자리이고, 해당 없는 섹션은 통째로 삭제한다. 안내 문구는 본문에 남기지 않는다.

```markdown
## 개요

<이 PR이 무엇을 하는지 1~3문장>

## 변경 배경

<왜 필요한 변경인지. 문제 상황, 요구사항, 관련 이슈>

Closes #<이슈 번호>

## 주요 변경 사항

- <변경 1>
- <변경 2>

## 테스트

- [ ] <실행한 테스트/검증 방법과 결과>
- [ ] <수동 확인 시나리오>

## 리뷰 포인트

<리뷰어가 특히 봐줬으면 하는 부분, 트레이드오프, 알려진 한계>

## 스크린샷

<UI 변경이 있을 때만>
```

## 작성 규칙

- 테스트 체크박스는 실제로 실행하고 통과한 것만 체크한다. 실패했거나 실행하지 못했으면 체크하지 않고 사유를 적는다.
- 추측으로 이슈 번호나 결과를 쓰지 않는다.
- Breaking change가 있으면 "변경 배경" 아래에 별도 문단으로 명시한다.
